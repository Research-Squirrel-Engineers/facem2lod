What this is

FACEM (facem.at) describes the fabrics of African Red Slip Ware found in Tunisia: for each fabric a representative sample and further samples, each with the sherd it was taken from, its form, type, dating, dimensions and the observations of the fabric under the binocular and in thin section. facem2lod turns the public pages into Linked Open Data: an ontology anchored in CIDOC-CRM, SKOS vocabularies for every controlled value, an instance graph, and a DCAT 3 description of the datasets.

Where to start
